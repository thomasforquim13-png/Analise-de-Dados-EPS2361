# Analise-de-Dados-EPS2361

Este repositório contém as análises, notebooks e scripts desenvolvidos para a disciplina de Análise de Dados do curso de Engenharia de Produção (UFSC).

## 🚀 Objetivo do Projeto
O objetivo é aplicar técnicas de ciência de dados para resolver problemas reais de engenharia, focando em análise exploratória, tratamento de dados e visualização.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.14+
* **Bibliotecas:** Pandas, Matplotlib, Seaborn
* **Ambiente:** VS Code + Jupyter Notebooks
* **Gestão:** GitHub

## 📁 Estrutura do Repositório
* `/data`: Bases de dados utilizadas (CSV/XLSX).
* `/notebooks`: Scripts Jupyter com as análises detalhadas.
* `/src`: Funções Python auxiliares.
